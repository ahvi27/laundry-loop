LaundryLoop — HTML, CSS, and vanilla JavaScript

RUN: Extract the ZIP and open index.html in a modern browser. No npm installation needed.

FEATURES: Add loads, choose a wash duration, start a countdown, advance through washing/drying/folding, filter loads, and delete loads.

Data saves in this browser using localStorage when available. This is a personal tracker, not a laundry service booking system. It does not sync across devices. The timer tracks elapsed time; status changes are manual.
